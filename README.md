# SKYBREAK ARENA — ブラッシュアップ版

[ブラウザでゲームをプレイ](https://sugark615-creator.github.io/skybreak-arena/)

5体からファイターを選ぶ、スマホ横画面対応の2D対戦アクションです。

## 遊び方

キャラクター、対戦相手、CPUの強さを選んで対戦開始。3カウントの後、3分・3ストック戦が始まります。
攻撃でダメージを蓄積させて相手を場外へ吹き飛ばします。時間切れは残りストック、次にダメージで勝敗を判定します。
「CPU同士のデモ対戦」では、ランダムに選ばれた異なる2体の対戦を観戦できます。選択中のCPU難易度が双方に適用され、結果画面からデモを再戦できます。

- 左右ボタン / A・D・左右キー：移動
- Aボタン / J：近接攻撃。長押しで3段コンボ
- Bボタン / K：通常ショット。MAXゲージ100%時は最大必殺技に切り替わります
- ↑ボタン / Space・W・上キー：ジャンプ
- Gボタン / L：ガード
- Ⅱボタン / P・Esc：一時停止。音量調整・選択画面へ戻る操作もここにあります
- ♪：音をオン／オフ

ゲージは攻撃命中・被弾・ガードで蓄積します。MAX発動で全消費し、MAX自身の命中では攻撃側ゲージを補充しません。
落下後は途中までのゲージを保持、再戦時はリセットします。メニューの選択・難易度・音量はこの端末のブラウザーに保存します。

## ファイター

| ファイター | 特徴 | 通常B技 | MAX |
|---|---|---|---|
| ARC | 扱いやすい速度と電撃 | THUNDER SHOT | MAX THUNDER |
| JET | 最速の移動・速い連射、軽い一撃 | PLASMA SHOT | STAR LASER |
| MIST | ゆっくり落下、地上＋空中3回ジャンプ | STAR SHOT | STAR CRASH（3方向） |
| BRICK | 重い一撃・吹き飛びにくさ、控えめな速度 | BOLT SHOT | FURNACE BREAK |
| SPRING | 高いジャンプと速い移動 | WIND SHOT | SKY CYCLONE |

ARC（雷の結晶ゴーレム）・JET（仮面のエアスケーター）・MIST（雲の精霊）は新規デザインで、各12ポーズの透過画像を使用します。BRICK・SPRINGは従来のデザインです。
旧キャラクター画像は保管されており、現行のゲームとビルドからは参照しません。BGMはユーザー提供曲 `assets/battle-theme.mp4`（ステレオAAC、約2分59秒）です。曲頭0.75秒と曲末2.83秒の無音を再生範囲から外し、対戦中は低負荷でループ再生します。ポーズは再生位置を保持し、効果音に合わせてBGMを短く下げます。読み込みに失敗した場合は、オリジナル曲「IGNITION」（`assets/ignition.wav`）へ自動的に切り替わります。

## スマホでテスト

Macと同じWi-Fiに接続し、サーバー起動時に表示される Network URL をスマホで開きます。
Macを起動したままにしてください。ゲームは横向き、選択メニューは縦向きでも操作できます。
端末の縦向き固定は解除してください。縦向き・タブ非表示・別アプリへの移動時は自動で一時停止します。
音声は開始ボタン等の操作後に有効になります。全画面／横向き固定はブラウザーが対応する場合のみ有効です。

## 起動と保存

必要に応じて `npm install` を実行し、以下で起動します。

```sh
npm run dev -- --host 0.0.0.0 --port 5196 --strictPort
```

ビルド：`npm run build`。配信対象は `dist/` です。
主な実装は `main-2d.js`、`polish.css`、`battle-audio.mjs`、`index.html`。
旧3D版の `main.js` と旧CSSは保管用で、このバージョンからは読み込みません。

## GitHub Pages

公開リポジトリの `main` ブランチへプッシュすると、`.github/workflows/deploy-pages.yml` がビルドと公開を実行します。
GitHubのリポジトリ設定では、PagesのSourceを `GitHub Actions` にします。

## 確認

`node verify-polish.mjs` でインストール済みChromeを使い、PC・スマホ横画面の5体選択、B/MAX、ゲージ消費、
一時停止、発射方向・半径を反映する命中判定、ジャンプ回数、結果画面を確認します。
テスト用状態操作はテストが通信を差し替えて追加するもので、ゲーム本体には含みません。
実機iPhone/Androidでの音声・全画面は端末ごとの確認が必要です。
